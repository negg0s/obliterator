# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | Yes                |
| 0.2.x   | Yes                |
| < 0.2.0 | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability or safety bypass in Obliterator:

1. **Do not open a public issue.**
2. Report the vulnerability privately through [GitHub Security Advisories](https://github.com/negg0s/obliterator/security/advisories/new).
3. If GitHub Advisories are unavailable, contact the maintainer directly via email at `security@negg0s.dev` or via repository contact channels.

### Please Provide:
- A description of the vulnerability and the potential impact.
- Affected versions.
- Reproducible steps or proof of concept.
- Target path, privileges held, and Windows version.

### Response Timeline
- Initial acknowledgment within 48 hours.
- Status update and patch evaluation within 7 days.
- Public release and advisory published after a fix is verified.
