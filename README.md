# obliterator

obliterator - консольная утилита для Windows, которая принудительно удаляет программы и заблокированные папки вместе со всеми процессами, службами, дескрипторами, правами доступа, остаточными файлами и записями реестра.

## Чем отличается от Revo и Geek Uninstaller

Revo Uninstaller и Geek Uninstaller ориентированы на штатную деинсталляцию: они запускают встроенный деинсталлятор программы, ждут его завершения, а затем ищут оставшиеся файлы и ключи реестра через сканирование файловой системы и реестра.

obliterator решает другую задачу:
- Не зависит от встроенных деинсталляторов и не запускает их код.
- Принудительно замораживает все процессы программы и их дочерние процессы через NtSuspendProcess, после чего завершает их без шанса на перезапуск сторожевыми таймерами (watchdog).
- Находит и закрывает блокирующие дескрипторы файлов в чужих процессах через дублирование с флагом DUPLICATE_CLOSE_SOURCE.
- Перехватывает владение файлами на группу Администраторы и сбрасывает запрещающие правила ACL.
- Не входит внутрь точек повторной обработки (junctions и symlinks), удаляя только саму ссылку и сохраняя целевые каталоги в безопасности.
- Работает полностью из командной строки и сценариев автоматизации, поддерживает вывод отчетов в формате JSON.

## Предупреждение

Инструмент выполняет необратимое удаление данных без возможности восстановления из корзины. Для работы требуются права администратора (запуск от имени Администратора).

## Установка

1. Скачайте `obliterator.exe` со страницы релизов GitHub.
2. Поместите исполняемый файл в любую удобную папку (например, `C:\Tools` или добавьте в переменную PATH).
3. При необходимости добавьте пункт в контекстное меню проводника:
   `obliterator --install-menu`

## Примеры команд

- Интерактивный режим выбора программы:
  `obliterator`

- Удаление программы по названию:
  `obliterator "Google Chrome"`

- Удаление по пути к папке:
  `obliterator "D:\Games\StubbornGame"`

- Предварительный просмотр плана без удаления:
  `obliterator "D:\Apps\MyApp" --dry-run`

- Удаление без запроса подтверждения:
  `obliterator "D:\Apps\MyApp" --yes`

- Агрессивное удаление возможных остатков:
  `obliterator "D:\Apps\MyApp" --yes --aggressive`

- Выгрузка отчета в формате JSON:
  `obliterator "D:\Apps\MyApp" --yes --json`

- Установка пункта "Force Obliterate" в контекстное меню папок:
  `obliterator --install-menu`

- Удаление пункта из контекстного меню:
  `obliterator --uninstall-menu`

## Список флагов

- `--dry-run`: сформировать и показать план действий без изменения системы.
- `--yes`, `-y`: пропустить запрос подтверждения перед выполнением.
- `--aggressive`: удалять возможные остатки на диске (частичные совпадения имен).
- `--no-backup`: не экспортировать удаляемые ключи реестра в файлы .reg.
- `--no-handle-kill`: не закрывать удаленные дескрипторы файлов через дублирование.
- `--timeout <sec>`: таймаут ожидания завершения процессов в секундах (по умолчанию 5).
- `--verbose`, `-v`: включить подробный отладочный вывод.
- `--json`: вывести итоговый отчет в формате JSON в stdout.
- `--install-menu`: добавить пункт в контекстное меню проводника для текущего пользователя.
- `--uninstall-menu`: удалить пункт из контекстного меню проводника.
- `--help`, `-h`: показать справку по аргументам.

## Коды возврата

- `0`: успешное выполнение (а также справка или отмена операции пользователем).
- `1`: ошибка (цель не найдена, неверные аргументы или системный сбой).
- `2`: успешно, но требуется перезагрузка для завершения удаления заблокированных драйверов или файлов.
- `3`: отказ по правилам безопасности (попытка удалить корень диска, системные каталоги Windows, профиль пользователя).

## Как это работает по шагам

1. Защитная проверка: проверка нормализованного пути цели по белому списку запрещенных системных зон (корни дисков, Windows, System32, Program Files, ProgramData, Users).
2. Завершение процессов: поиск всех процессов, запущенных из целевой папки, процессов с загруженными оттуда модулями и их потомков. Массовая приостановка через NtSuspendProcess с последующим TerminateProcess.
3. Снятие блокировок файлов: опрос Restart Manager и системных дескрипторов. Закрытие дескрипторов файлов цели через DuplicateHandle с DUPLICATE_CLOSE_SOURCE.
4. Службы и задачи: остановка зависимых служб, удаление служб и драйверов через Service Control Manager, удаление связанных задач через COM Task Scheduler.
5. Физическое удаление: итеративный обход папки снизу вверх (файлы, затем пустые каталоги). Удаление файлов в пуле потоков. При ошибке доступа сброс ACL и назначение владельцем Administrators. Для файлов, удерживаемых ядром, планирование удаления при перезагрузке через MoveFileExW.
6. Очистка реестра: резервный экспорт ключей в .reg в %LocalAppData%\obliterator\backup, удаление веток Uninstall, автозагрузки Run/RunOnce, контекстных меню HKCR, ключей продукта в Software.
7. Очистка остатков: поиск папок в AppData и ProgramData, ярлыков на Рабочем столе и в Пуск, правил брандмауэра Windows.
8. Отчет: детерминированный вывод итоговой статистики в текстовом виде или JSON.

## Сборка из исходников

Требования:
- Windows 10/11 x64 или ARM64
- Visual Studio 2022/2026 (MSVC с поддержкой C++20)
- CMake 3.20+

Сборка одной командой:
```cmd
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release && cmake --build build --config Release
```

Или через CMake Presets:
```cmd
cmake --preset release
cmake --build --preset release
ctest --preset release --output-on-failure
```

Исполняемый файл будет собран в `build\release\obliterator.exe` (или `build\obliterator.exe`).
